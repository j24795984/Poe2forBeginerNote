# 影片整理－深淵

> 內容狀態：與既有的「深淵－基本說明」及「賺錢策略－深淵」高度涵蓋。現階段仍依第一部影片完整保留，尚未進行逐段比較、校訂與整合。
>
> 來源範圍：E01、E02，約 09:05～10:36。

## 1. 一般深淵

1. 觸發地圖上的深淵裂縫。
2. 沿著裂縫移動並清除怪物。
3. 關閉沿途坑洞。
4. 完成最後一個深淵。
5. 取得深淵物品、古老骨頭、寶庫或地下入口。

## 2. 無盡深淵

完成區域中的最後一個深淵後，有機率出現通往無盡深淵的入口。地下區域包含更強的深淵怪物與特殊獎勵，高階內容可能出現深淵頭目。

## 3. 靈魂之井與褻瀆

- 古老骨頭可用於靈魂之井。
- 可對符合條件的裝備、珠寶或換界石進行褻瀆。
- 不同骨頭對應不同物品類型、詞綴或風險。
- 部分褻瀆可能摧毀物品，使用前應閱讀道具說明並查價。

## 4. 大型深淵與頭目

- 輿圖上可出現大型深淵裂縫或被深淵佔據的地圖。
- 完成後可推進深淵任務與頭目內容。
- 高階頭目可能掉落後續巔峰挑戰所需的邀請。

本段在第一部影片中只做概覽；一般深淵、無盡深淵、大型事件、褻瀆與頭目之間的詳細差異，留待與專題文件逐段比較。

## 5. 天賦配置方向

深淵天賦可依目標選擇：

- 增加深淵坑洞與怪物數量。
- 增加通往無盡深淵的機率。
- 增加古老骨頭、深淵之眼或特殊物品。
- 強化被深淵佔據的地圖。
- 發展一般刷怪、褻瀆材料、無盡深淵或頭目路線。
