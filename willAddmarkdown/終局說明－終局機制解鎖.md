# 終局說明－終局機制解鎖

> 版本基準：POE2 0.5 版。
>
> 內容來源：第一部影片的 A01、A02、A03、A04 與 G01。本文定位為新手進入終局後的共通導航，不深入展開各聯盟機制的農法。

## 1. 終局機制總覽

進入輿圖後，玩家會接觸祭祀、譫妄、裂痕、深淵與探險等終局機制。初期目標不是立刻投入昂貴門票，而是先完成各機制的據點、任務與基礎輿圖天賦。

遇到下列情況時，應先確認機制據點與任務進度：

- 不知道任務下一步要去哪裡。
- 已取得任務道具，但輿圖沒有顯示目標。
- 尚未取得對應機制的輿圖天賦點。
- 想挑戰頭目，但還沒完成前置流程。
- 不清楚目前應該出售門票，還是自行使用。

## 2. 終局機制快速傳送

0.5 版的終局機制設有對應據點與快速移動功能。揭露據點後，可更方便地返回相關區域，進行下列操作：

- 與機制 NPC 對話。
- 回報或繼續任務。
- 查看據點周圍尚未完成的地圖。
- 處理特殊區域、頭目或關鍵道具。

快速傳送的主要作用，是降低往返與尋路成本；它不會代替據點周圍地圖、任務條件或 NPC 對話。

## 3. 輿圖搜尋

任務卡住時，可先使用輿圖搜尋功能尋找：

- 特定終局機制。
- 已揭露的機制據點。
- 任務指定地圖或特殊區域。
- 祭祀、譫妄、裂痕、深淵與探險等內容。

建議檢查順序：

1. 搜尋機制或任務名稱。
2. 確認目標是否已揭露。
3. 檢查據點周圍是否仍有未完成地圖。
4. 確認任務道具是否需要放在角色背包。
5. 完成地圖後，回到據點與 NPC 對話。

## 4. 初期機制天賦點

各終局機制的據點周圍設有指定地圖。完成這些地圖與相關任務後，可以先取得部分機制輿圖天賦點。

這些點數的價值在於：

- 不必先購買昂貴門票或挑戰巔峰頭目。
- 可先配置一般機制的穩定性與基礎收益節點。
- 降低新手直接投入高難度內容的風險。
- 為後續門票、頭目與高階農法建立基本配置。

巔峰頭目與高階任務通常提供後續點數或專精解鎖；初期不必以它們作為第一個目標。

## 5. 建議解鎖順序

1. 揭露各終局機制的據點。
2. 使用快速傳送與輿圖搜尋確認位置。
3. 完成據點周圍的指定地圖。
4. 與相關 NPC 對話，取得初期機制輿圖天賦點。
5. 完成各機制的基本任務線與角色永久獎勵。
6. 依角色強度配置一般機制天賦。
7. 再決定門票要出售或自行使用。
8. 最後進入巔峰頭目與高投入農法。

核心原則：

> 先完成免費解鎖與任務進度，再投入門票和高成本強化道具。
