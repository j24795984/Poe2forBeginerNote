# 基本說明－裂痕

本篇以裂痕的機制用途與整體流程為主。任務順序僅簡單說明，不展開逐步攻略。

## 一、裂痕是什麼
裂痕是輿圖中的限時戰鬥機制。
玩家在地圖中開啟「不穩定裂痕」後，裂痕怪物會持續出現。玩家必須快速擊殺怪物，延長裂痕持續時間並使裂痕向外擴張。
裂痕穩定後，會出現更強的敵人與後續獎勵。

主要玩法可以概括為：
1. 開啟不穩定裂痕。
2. 快速擊殺裂痕怪物。
3. 延長裂痕並持續推進。
4. 擊殺穩定後出現的強敵。
5. 取得裂痕斷片、巢裔之血、胎贈及其他掉落物。

## 二、裂痕的整體流程
裂痕機制主要由以下循環構成：
1. 在輿圖中進入含有裂痕的地圖。
2. 開啟不穩定裂痕並擊殺裂痕怪物。
3. 收集裂痕斷片、巢裔之血、胎贈與一般掉落物。
4. 收集300個裂痕斷片，合成「啟示之胎贈」。
5. 將啟示之胎贈放入創生之樹，取得裂痕石。
6. 將裂痕石放在角色背包內，在輿圖揭露裂痕區域。
7. 完成區域周圍的裂痕事件、巢穴與頭目內容。
8. 繼續完成一般裂痕，取得巢裔之血與胎贈。
9. 將資源投入創生之樹，換取或製作其他裂痕產物。

簡化流程為：
一般裂痕 → 裂痕斷片、巢裔之血、胎贈 → 創生之樹 → 裂痕石或其他產物 → 裂痕區域、巢穴與頭目 → 返回一般裂痕繼續累積資源

## 三、主要掉落物
| 產物 | 主要用途 |
| :--- | :--- |
| 裂痕斷片 | 收集300個後合成啟示之胎贈 |
| 巢裔之血 | 創生之樹的主要消耗資源 |
| 胎贈 | 放入創生之樹，產生不同獎勵或製作結果 |
| 裂痕石 | 揭露輿圖上的裂痕區域，推進巢穴與後續內容 |
| 催化劑 | 用於強化飾品上的特定詞綴類型 |
| 裂痕限定裝備 | 由胎贈、創生之樹或裂痕相關內容取得 |
| 一般掉落物 | 通貨、金幣及其他地圖物品 |

## 四、巢裔之血
巢裔之血是裂痕機制的主要消耗資源。
玩家可以透過完成一般裂痕、擊殺裂痕怪物及相關獎勵取得巢裔之血，再將其投入創生之樹，處理不同類型的胎贈。
巢裔之血本身不是最終產物，而是裂痕資源轉換與裝備製作的核心材料。

主要用途包括：
* 培育或處理胎贈。
* 取得催化劑。
* 產生裂痕限定裝備。
* 進行高波動的特定裝備製作。
* 推進裂痕石等進度內容。

## 五、胎贈
胎贈是裂痕機制中的轉換與製作媒介。
玩家需要將胎贈放入創生之樹，並消耗一定數量的巢裔之血，使胎贈產生對應結果。
依照用途，可以分成三個方向：

1. **進度型胎贈**：用於推進裂痕機制的後續內容。例如「啟示之胎贈」可以透過裂痕斷片合成，再於創生之樹取得裂痕石。
2. **獎勵型胎贈**：用於取得催化劑或其他裂痕產物。這類胎贈適合希望將巢裔之血轉換成可交易物品的玩家。
3. **製作型胎贈**：用於產生或加工特定裝備。其結果通常具有較高隨機性，可能取得普通物品，也可能產出具有高價詞綴的裝備。

不同胎贈可能具有不同的：產物類型、物品等級、巢裔之血消耗量、製作風險、市場價值。
投入前應先確認胎贈的產物方向，避免把巢裔之血消耗在不符合目前需求的項目上。

## 六、創生之樹
創生之樹是裂痕資源的主要處理系統。
基本操作流程為：
1. 取得胎贈。
2. 將胎贈放入創生之樹。
3. 確認胎贈可能產生的結果。
4. 消耗所需的巢裔之血。
5. 取得裂痕石、催化劑、裝備或其他裂痕產物。

創生之樹的主要功能可以分成：
* 將裂痕斷片轉換為後續進度。
* 將巢裔之血轉換為可使用或可交易的物品。
* 製作裂痕限定裝備。
* 提供高投入、高波動的裝備製作方式。

## 七、裂痕石
裂痕石是從一般裂痕進入後續裂痕內容的關鍵物品。
取得流程為：收集300個裂痕斷片 → 合成啟示之胎贈 → 將啟示之胎贈放入創生之樹 → 取得裂痕石。

使用裂痕石時，需要注意：
* 裂痕石必須放在角色背包內。
* 符合條件後，輿圖才會顯示可揭露的裂痕區域。
* 揭露區域後，可以進行周圍的裂痕系列事件。
* 後續內容包含裂痕巢穴、核心與頭目。

## 八、裂痕巢穴與後續內容
裂痕巢穴屬於裂痕石揭露後的進階內容。
玩家可能需要：
1. 進入指定的裂痕巢穴。
2. 保護艾里絲。
3. 擊退持續出現的敵人。
4. 協助艾里絲完成摧毀核心的程序。
5. 完成相關頭目。
6. 返回據點與NPC對話，繼續後續任務。

如果防守失敗、關鍵NPC死亡或沒有完成後續對話，可能會造成任務看似沒有繼續推進。

## 九、任務流程簡述
裂痕任務主要是引導玩家依序接觸不同層級的裂痕內容：
1. 接觸看守者的修道院與周邊裂痕。
2. 完成據點周圍的指定地圖。
3. 取得裂痕相關輿圖天賦點。
4. 透過一般裂痕收集裂痕斷片與相關資源。
5. 取得裂痕石並揭露後續區域。
6. 完成裂痕巢穴、核心與頭目內容。
7. 返回據點完成對話，解鎖後續裂痕內容。

任務本身是線性引導，不需要在基本說明中逐項列出每個任務名稱。

## 十、常見卡關位置
* 裂痕石沒有放在角色背包內。
* 尚未完成據點周圍要求的指定地圖。
* 巢穴防守過程失敗。
* 艾里絲未能完成摧毀核心。
* 擊敗頭目後沒有返回據點完成NPC對話。
* 將任務所需的胎贈或裂痕產物提前使用。
