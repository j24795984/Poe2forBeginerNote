# 賺錢策略－BOSS 門票

## 1. 目標

快速向輿圖外圍拓展，尋找帶有光柱標記的據點與特殊頭目區域。

利用高「換界石掉落機率」增加據點頭目掉落的門票、碎片或特殊任務道具數量，再將取得的道具出售獲利。

此策略的主要收益來自據點頭目，因此沿途地圖以快速通關為主，不需要完整清圖。

---

## 2. 執行方式

1. 使用低成本換界石快速完成普通地圖。
2. 配置多里亞尼的輿圖能力，加快地圖探索與新區域生成。
3. 使用帶有「譫妄之鏡」的廉價碑牌。
4. 進入地圖後，觀察譫妄進度條判斷頭目方向：
   - 進度增加：正在接近頭目。
   - 進度減少：正在遠離頭目。
5. 沿途只處理順路且有價值的內容，不刻意完整清圖。
6. 發現據點後，先切換為適合據點頭目的賈多輿圖配置。
7. 使用高「換界石掉落機率」的換界石開啟據點。
8. 擊殺據點頭目，取得門票、碎片或特殊任務道具。
9. 繼續向輿圖外圍拓展，尋找下一個據點。

> **簡化流程：**低成本拓圖 → 尋找據點 → 切換賈多 → 使用高掉落率換界石 → 擊殺據點頭目 → 出售道具。

---

## 3. 執行條件

### 3.1 角色條件

- 具備足夠的移動速度與清圖能力。
- 能穩定擊殺據點頭目。
- 不需要頂級機體，但移動速度與頭目擊殺速度會直接影響每小時收益。

### 3.2 換界石條件

普通拓圖與據點頭目應使用不同的換界石：

| 用途 | 建議條件 |
|---|---|
| 普通拓圖 | 使用低成本換界石，以快速通關為主 |
| 一般據點 | 換界石掉落機率約 100% 以上 |
| 高價據點 | 換界石掉落機率約 100%～120% 以上，並搭配頭目掉落相關效果 |

整理換界石時，可優先保留基礎掉落率約 65%～70% 以上的換界石，再視成本使用崇高石補充詞綴。

### 3.3 碑牌條件

沿途拓圖可使用帶有以下效果的碑牌：

- 地圖內含有譫妄之鏡。
- 增加換界石掉落機率。
- 增加地圖頭目掉落的換界石數量。
- 強化頭目或據點獎勵。

普通拓圖碑牌不宜投入過高成本；昂貴碑牌應保留給高價據點或專門收益策略。

### 3.4 輿圖配置

#### 普通拓圖：多里亞尼

- 加快地圖探索。
- 解鎖周圍節點。
- 提高發現據點與特殊區域的效率。

#### 據點頭目：賈多

- 強化據點及頭目相關獎勵。
- 必須在開啟據點地圖前完成切換。

### 3.5 管理條件

- 使用輿圖書籤記錄未完成據點及拓圖方向。
- 將普通換界石與據點專用換界石分開存放。
- 執行前先確認門票與特殊道具的市場價格。
- 準備足量的低成本換界石與譫妄碑牌，避免頻繁中斷。

## 4. 道具價值

以下為影片錄製期間的估值，只適合用來判斷相對價值，不代表目前固定價格。

| 道具／收益來源 | 估值 | 處理方式 |
|---|---:|---|
| 裂痕相關門票 | 約 4 D 以上 | 高價，優先出售 |
| 原初搖籃 | 約 3 D | 查價後出售 |
| 原初光輝 | 約 2 D 以上 | 查價後出售 |
| 風化危機碎片 | 約 2～4 D | 依市場價格出售 |
| 其他特殊頭目門票或碎片 | 約 1～4 D | 逐件查價 |
| 單一高價據點收益 | 約 4～9 D | 以掉落 2 份道具估算 |
| 一般高速機體 | 約 30 D／小時 | 受到據點密度影響 |
| 高完成度高速機體 | 約 40～50 D／小時 | 需要高跑速與穩定輸出 |

### 價值判斷原則

- **4 D 以上：**高價道具，據點優先度最高。
- **2～4 D：**主要收益來源，適合穩定出售。
- **1～2 D：**視路線成本與擊殺時間決定是否執行。
- **1 D 以下：**除非順路或可大量取得，否則不建議特別繞路。

實際收益會受到據點分布、角色速度、門票價格、換界石與碑牌成本，以及頭目掉落 1～3 份道具等因素影響。
