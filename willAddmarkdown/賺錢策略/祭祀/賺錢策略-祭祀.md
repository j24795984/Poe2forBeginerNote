# 賺錢策略－祭祀

> 版本基準：POE2 0.5 版祭祀系統。本文不記錄固定市場價格；預兆、傳奇、門票與魔偶的價值會隨聯盟時間及流派需求變動，執行前應重新查價。

## 1. 策略目標

祭祀的收益來自「以貢禮選擇獎勵」，而非單純依靠地面掉落。

主要收益包括：

- 高需求預兆
- 高價傳奇物品
- 覲見國王
- 迷霧之王限定傳奇
- 祭祀碑牌
- 無名之儀的洞見獎賞
- 迷霧王后與王后的祭祀產出的特殊魔偶

核心原則：

> 先保留確定有價值的恩惠，再用剩餘貢禮重骰或轉換成覲見國王進度。

---

## 2. 三種賺錢方式

### 低投入：一般祭祀

適合剛解鎖祭祀、角色強度普通或資金不足的玩家。

執行方式：

- 完成地圖內全部祭祀神壇。
- 兌換高需求預兆與高價傳奇。
- 貢禮不足時，推遲值得保留的物品。
- 沒有好物時，再考慮重骰恩惠。
- 最後將未花費的貢禮轉為覲見國王進度。

此階段的收益較穩定，主要風險是判斷錯物品價值或錯誤使用貢禮。

### 中投入：專精貢禮與恩惠

完成祭祀天賦配置後，利用更高貢禮、更多恩惠、額外重骰與較低推遲成本，提高每張地圖找到高價物品的機會。

適合：

- 能快速完成全部祭祀神壇。
- 熟悉常見預兆與傳奇價值。
- 能承受祭祀怪物反覆復活後的難度。
- 願意逐件檢查恩惠，而非只依物品外觀判斷。

### 高投入：頭目與無名之儀

流程：

> 累積覲見國王 → 挑戰迷霧之王 → 取得國王首級 → 完成無名之儀 → 收集假人斷片 → 挑戰迷霧王后

收益上限較高，但需要承擔：

- 覲見國王的使用成本或出售機會成本。
- 連續多張地圖失敗的風險。
- 累積怪物、地圖頭目與額外詞綴造成的難度。
- 高階掉落價格波動與銷售速度。

若角色無法穩定完成頭目或無名之儀，直接出售可交易的門票與產物通常較安全。

---

## 3. 貢禮使用順序

每次查看恩惠時，可依下列順序決策：

1. **先查高價物品**：確認預兆、傳奇及特殊物品的即時價格。
2. **能買就直接兌換**：避免後續誤按重骰或離開地圖。
3. **買不起但值得保留就推遲**：支付部分貢禮，等待後續再次出現。
4. **沒有值得保留的物品才重骰**：重骰前先估算剩餘貢禮是否足以購買新物品。
5. **最後處理剩餘貢禮**：將無法有效使用的部分轉為覲見國王進度。

簡化判斷：

| 當前狀況 | 建議操作 |
|---|---|
| 出現高價物品且貢禮足夠 | 直接兌換 |
| 出現高價物品但貢禮不足 | 推遲 |
| 沒有高價物品且剩餘貢禮充足 | 重骰 |
| 沒有高價物品且貢禮不足以有效重骰 | 轉為覲見國王進度 |
| 不確定物品價值 | 先查價，不要立即重骰 |

---

## 4. 一般祭祀執行流程

1. 進入含有祭祀的地圖。
2. 清除祭祀法陣內的怪物。
3. 啟動並完成第一座祭祀神壇。
4. 依蝗蟲指引前往下一座神壇。
5. 完成地圖內全部祭祀，盡量提高總貢禮。
6. 查看恩惠，先處理高價或需推遲的物品。
7. 視剩餘貢禮決定是否重骰。
8. 將最後剩餘貢禮轉為覲見國王進度。

### 地圖與角色選擇

- 優先選擇動線短、神壇容易尋找的地圖。
- 狹窄祭祀範圍需要足夠生存、控場與範圍清怪能力。
- 若地圖頭目可能進入祭祀怪物池，應確認角色能重複處理該頭目。
- 避免同時疊加角色無法承受的換界石、祭祀與怪物詞綴。

---

## 5. 祭祀天賦配置方向

### 穩定收益型

優先考慮：

- 增加怪物提供的貢禮。
- 增加恩惠之物數量。
- 增加重骰次數或免費重骰機率。
- 降低推遲成本並讓推遲物更快再次出現。

適合以預兆、傳奇及穩定累積覲見國王為主的玩家。

### 門票進度型

優先考慮：

- 提高獻祭貢禮時的覲見國王進度。
- 讓已消耗的部分貢禮也能提供覲見國王進度。

適合目標明確為迷霧之王、無名之儀與後續頭目的玩家。

### 高風險收益型

可考慮：

- 增加魔法、稀有或特殊怪物。
- 讓祭祀出現在召喚法陣上並加入額外頭目。
- 增加無名之儀持續地圖數或地圖額外詞綴。
- 解鎖王后的祭祀。

此方向會增加怪物密度與獎勵上限，但也會明顯提高死亡或無法完成的風險。

---

## 6. 無名之儀地圖選擇

無名之儀會把怪物、頭目與部分強化效果帶到後續地圖，因此每次選擇都會影響整個流程。

### 選擇優先度

1. 排除角色無法處理的地圖詞綴。
2. 排除過度危險或耗時的地圖頭目。
3. 優先動線短、祭祀位置容易接近的地圖。
4. 再比較洞見獎賞與洞見擴散效果。
5. 只有在角色能穩定完成時，才選擇高報酬、高難度組合。

### 風險控制

- 不要只為單一高價洞見獎賞，選擇會讓後續整套流程失敗的詞綴。
- 早期加入的難纏怪物會在後續反覆出現，應比單張地圖更保守地評估。
- 若目標是首次解鎖，優先完成流程；熟悉後再追求收益最大化。
- 進入前先檢查裝備、抗性、藥劑、護符與死亡成本。

---

## 7. 收益判斷

| 收益來源 | 價值定位 | 建議處理 |
|---|---|---|
| 一般預兆 | 穩定或中低價收益 | 累積後批量出售 |
| 製作用高需求預兆 | 主要收益 | 逐件查價，避免低估 |
| 一般傳奇 | 價格差異大 | 看詞綴數值與市場需求 |
| 稀有祭祀傳奇 | 高價但低機率 | 單獨查價 |
| 祭祀碑牌 | 維持農法的消耗品 | 比較自用增益與出售價格 |
| 覲見國王 | 門票型收益 | 比較直接出售與自打期望值 |
| 迷霧之王產物 | 頭目收益 | 逐件查價 |
| 洞見獎賞 | 無名之儀額外收益 | 依獎賞內容與完成風險選擇 |
| 腐化魔偶／王后魔偶 | 高階特殊產物 | 依效果與流派需求查價 |

### 不宜固定估價的原因

- 預兆會隨製作流派與聯盟階段大幅波動。
- 傳奇物品可能因詞綴數值、腐化結果或特定流派而產生巨大價差。
- 門票價格會受到頭目掉落、挑戰需求與角色普及度影響。
- 魔偶屬於特殊產物，成交量較低時不應只看單一掛價。

---

## 8. 投入判斷

自用門票或進入無名之儀前，可先比較：

> 預期產物價值 − 門票出售價值 − 地圖與碑牌成本 − 失敗風險 − 交易時間

### 適合直接出售

- 角色尚未完成祭祀天賦配置。
- 無法穩定擊敗迷霧之王或完成連續祭祀地圖。
- 不熟悉頭目掉落與魔偶價值。
- 資金不足以承擔數次低收益結果。

### 適合自行使用

- 能穩定完成高難度祭祀與頭目。
- 已取得關鍵祭祀天賦。
- 熟悉預兆、傳奇與特殊產物市場。
- 有足夠樣本與資金承擔收益波動。

---

## 9. 常見錯誤

- 尚未檢查恩惠價值便直接重骰。
- 貢禮不足時忘記推遲高價物品。
- 為了累積覲見國王，把原本可換取高價物品的貢禮全部獻祭。
- 只完成部分神壇，導致總貢禮與可用重骰次數不足。
- 未計入覲見國王的出售價值，直接進場挑戰頭目。
- 無名之儀只看獎勵，不檢查累積詞綴與地圖頭目。
- 在角色尚未成熟時配置過多高難度怪物節點。
- 將「王后的祭祀」與「迷霧王后」頭目戰視為同一機制。
- 依影片錄製時的價格判斷現行市場，沒有重新查價。

---

## 10. 快速決策

| 玩家狀態 | 建議策略 |
|---|---|
| 剛接觸祭祀 | 先完成凱爾塔斯任務與輿圖天賦點 |
| 不熟悉預兆與傳奇 | 先查價；高價物品買不起時使用推遲 |
| 角色可穩定刷祭祀 | 配置貢禮、恩惠與重骰相關天賦 |
| 想累積頭目門票 | 配置覲見國王進度相關天賦 |
| 無法穩定打王 | 出售可交易門票與高階產物 |
| 已完成高階解鎖 | 發展無名之儀與王后的祭祀農法 |
| 裝備與資金成熟 | 追求高難度洞見獎賞與迷霧王后產物 |
