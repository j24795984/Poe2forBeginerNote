# 賺錢策略－裂痕

本篇整理自中國服攻略。價格、產量、詞綴與收益屬於特定版本及市場環境，目前僅作為策略原理參考，不代表台服實際行情。

## 一、策略概覽
裂痕賺錢策略的核心，是在受到多個裂痕碑牌影響的高階地圖中，快速完成大量裂痕，取得巢裔之血、通貨、金幣及胎贈。
取得巢裔之血後，再依目標投入創生之樹，轉換成催化劑或特定裝備。

目前可以分成三種策略：

| 策略 | 主要產物 | 收益特性 | 適合玩家 |
| :--- | :--- | :--- | :--- |
| 催化劑農法 | 巢裔之血、催化劑 | 相對穩定，但受市場價格影響 | 第一次建立裂痕農圖循環的玩家 |
| 召喚腰帶製作 | 高價腰帶 | 高投入、高波動 | 資金充足且熟悉裝備估價的玩家 |
| 高譫妄速刷 | 通貨、催化劑、金幣 | 收益來源分散，角色門檻高 | 能快速完成高難度地圖的玩家 |

## 二、共通前置準備

### 1. 角色能力
角色需要能穩定完成高階稀有換界石，並在裂痕開啟後快速處理大量怪物。
評估重點：
* 能否快速清除裂痕怪物。
* 能否在裂痕關閉前持續推進。
* 面對稀有裂痕怪物時，能否維持清圖速度。
* 是否能穩定承受地圖上的危險詞綴。
* 是否經常死亡或需要頻繁回城。
* 拾取與整理物品是否占用過多時間。

如果角色只能勉強通關，應先降低地圖難度或碑牌投入。
裂痕農法高度依賴清圖速度。即使單張地圖的理論收益較高，死亡或清圖過慢仍會降低每小時收益。

### 2. 地圖條件
原攻略採用：
* 城市生態群系。
* T15稀有換界石。
* 六個地圖詞綴。
* 多個裂痕碑牌共同覆蓋。
* 適合快速移動及連續清怪的地形。

原攻略透過「工業提升」，使地圖額外受到一個碑牌影響，達成四碑牌覆蓋。此節點名稱與效果目前暫不驗證。

### 3. 輿圖天賦方向
優先考慮：
* 增加裂痕怪物群大小。
* 增加裂痕內容出現機率。
* 增加稀有裂痕怪物。
* 強化稀有裂痕怪物的產出。
* 增加地圖受到的碑牌數量。
* 提高整體稀有怪物或地圖內容收益。

## 三、裂痕碑牌選擇
裂痕碑牌的基本功能，是讓受影響的地圖加入裂痕內容。

重要效果方向包括：

| 效果 | 策略定位 |
| :--- | :--- |
| 增加地圖內找到的巢裔之血數量 | 催化劑與裝備製作的核心 |
| 增加裂痕怪物群大小 | 增加怪物、巢裔之血與一般掉落 |
| 增加稀有裂痕怪物的效用 | 通貨與高譫妄速刷 |
| 增加地圖內找到的物品稀有度 | 放大一般物品收益 |
| 增加地圖內找到的胎贈數量 | 補充創生之樹消耗材料 |
| 不穩定裂痕穩定後生成額外稀有怪物 | 增加稀有怪物產出 |
| 增加特定裂痕敵人出現機率 | 特殊敵人或相關掉落農法 |

不同策略的優先方向：

| 策略 | 優先效果 |
| :--- | :--- |
| 催化劑農法 | 巢裔之血數量、裂痕怪物群大小 |
| 召喚腰帶製作 | 巢裔之血數量、裂痕怪物群大小 |
| 高譫妄速刷 | 額外稀有怪物、稀有怪物效用、怪物群大小、巢裔之血數量 |

購買碑牌時，應同時比較：詞綴組合、數值高低、剩餘使用次數、單張價格、實際可以覆蓋的地圖數量。

## 四、策略一：催化劑農法
### 核心目標
大量取得巢裔之血，再透過胎贈與創生之樹將其轉換為催化劑。

### 配置方向
* 選擇適合快速清怪的城市地圖。
* 使用多個裂痕碑牌共同覆蓋。
* 優先選擇增加巢裔之血數量的碑牌。
* 同時增加裂痕怪物群大小。
* 使用角色能夠穩定速刷的高階稀有換界石。

### 執行流程
1. 選擇受到多個裂痕碑牌影響的地圖。
2. 確認碑牌的巢裔之血加成、使用次數及成本。
3. 使用角色能穩定完成的高階換界石。
4. 進圖後優先完成裂痕。
5. 略過與策略無關的低價值內容。
6. 完成一輪地圖後，再集中整理巢裔之血與掉落物。
7. 使用胎贈與創生之樹取得催化劑。
8. 扣除換界石、碑牌與胎贈成本，計算實際淨收益。

### 原攻略產量試算
原攻略假設每個裂痕基礎取得700點巢裔之血，並受到四個各增加60%巢裔之血數量的碑牌影響：
`700 ×（1＋0.6 × 4）＝2,380`

如果每張地圖完成四個裂痕：
`2,380 × 4＝9,520點巢裔之血`

十張地圖的簡化估算為：
`9,520 × 10＝95,200點巢裔之血`

這組數值只用於說明多碑牌加成的計算概念，不代表實際保證產量。實際結果還會受到：每張地圖的裂痕數量、裂痕怪物群大小、裂痕完成度、輿圖天賦、地圖詞綴、碑牌效果、角色清怪速度等因素影響。

### 主要風險
* 裂痕碑牌價格提高。
* 胎贈需要另外購買。
* 催化劑價格下降。
* 角色清圖效率不足。
* 原攻略產量不符合目前版本。

## 五、策略二：召喚腰帶製作
### 核心目標
將巢裔之血投入創生之樹製作腰帶，追求高價召喚物詞綴。原攻略的主要目標為：**全部召喚物技能等級＋2**。
其他可能具有價值的方向包括：召喚物傷害、濺射傷害、移動速度、範圍效果。腰帶的實際價值仍需依照基底、詞綴組合、數值及當期流派需求判斷。

### 執行流程
1. 沿用催化劑農法取得大量巢裔之血。
2. 準備對應的製作型胎贈。
3. 將胎贈與巢裔之血投入創生之樹。
4. 檢查產出腰帶的基底與完整詞綴。
5. 出售中價值或高價值成品。
6. 持續記錄總投入與實際回收。

### 收益特性與適用條件
這是一種高波動製作策略。原攻略曾記錄約消耗200,000點巢裔之血，才取得一條具有目標詞綴的腰帶。這只是單次經驗，不能視為固定機率。
* **適合**：已有穩定資金、能承受連續製作失敗、熟悉裝備詞綴、能正確評估腰帶價值、不依賴這套策略支付下一輪刷圖成本。
* **不適合**：資金不足的新手、尚未理解裝備詞綴價值、無法承受長時間沒有高價產出、將全部資金投入單一製作結果的玩家。

## 六、策略三：高譫妄裂痕速刷
### 核心目標
透過高譫妄程度的裂痕地圖，同時取得：稀有裂痕怪物掉落的通貨、巢裔之血、催化劑、金幣、胎贈、其他裂痕產物。

### 配置方向
* 使用適合快速清怪的城市地圖。
* 將地圖提高至高譫妄程度。
* 增加額外稀有怪物。
* 強化稀有裂痕怪物效用。
* 保留裂痕怪物群大小與巢裔之血數量。
* 使用能快速完成高難度裂痕的角色。

這套策略不能只求完成地圖。若清怪速度大幅下降、頻繁死亡或需要多次返回地圖，實際收益可能低於一般裂痕農法。

### 物品稀有度
原作者的角色具有113%物品稀有度，但不應將其視為進入策略的固定門檻。當角色已具備足夠傷害與生存後，可以考慮增加物品稀有度；但不應為了物品稀有度犧牲過多清圖速度。
效果優先序可暫時整理為：稀有怪物效用 > 額外稀有怪物 > 裂痕怪物群大小 > 巢裔之血數量 > 物品稀有度。

### 原攻略收益紀錄
原攻略以十張地圖為一輪，記錄：
* 裂痕稀有怪物掉落通貨：約50D。
* 巢裔之血兌換催化劑：約40D。
* 裂痕掉落金幣：數百萬枚 (原文另以100萬金幣約可轉換為5D計算)。
*(以上屬於中國服特定版本及市場紀錄，不能直接套用至台服，也不能視為保證收益。)*

### 主要風險
* 高譫妄程度會顯著提高地圖難度。
* 高品質碑牌與換界石成本較高。
* 通貨掉落具有較大波動。
* 金幣的用途與價值可能不適用於台服。
* 清圖效率不足時，收益可能低於普通裂痕。
* 死亡會直接增加時間與地圖成本。

## 七、速刷操作原則
### 地圖內
* 優先完成裂痕與主要收益內容。
* 略過低價值或不符合策略目標的內容。
* 使用物品篩選器隱藏低價裝備與物品。
* 不為低價掉落物折返。
* 多個裂痕距離接近時，可依角色能力連續開啟。
* 使用延遲傷害技能時，可提前放置技能後繼續移動。
* 避免在已完成的區域反覆繞路。

### 地圖外
* 預先準備一整輪需要的換界石與碑牌。
* 每輪結束後再集中整理倉庫。
* 將可直接出售與需要估價的物品分開。
* 分別記錄成本、已出售收益及未出售庫存。
* 不要把尚未售出的標價物品全部視為實際收入。

## 八、收益計算方式
真正需要比較的是每小時淨收益，而不是單純查看掉落物的標價。
* `淨收益 ＝ 已出售收入 ＋ 可合理變現的庫存價值 － 換界石成本 － 碑牌成本 － 胎贈成本 － 其他消耗`
* `每小時淨收益 ＝ 淨收益 ÷ 總耗時`

總耗時應包含：購買材料、準備地圖、實際刷圖、整理背包與倉庫、估價與販售、死亡與失敗造成的時間損失。
建議至少測試20～30張地圖，再判斷策略是否適合自己的角色。

## 九、策略選擇
| 玩家狀態 | 建議策略 |
| :--- | :--- |
| 第一次嘗試裂痕農法 | 催化劑農法 |
| 可以穩定速刷高階地圖 | 提高碑牌投入與怪物群大小 |
| 可以快速處理高譫妄地圖 | 高譫妄裂痕速刷 |
| 資金充足且熟悉裝備估價 | 召喚腰帶製作 |
| 資金不足或角色尚未成形 | 降低地圖難度，先累積巢裔之血 |
| 無法承受製作波動 | 出售巢裔之血相關產物或製作催化劑 |

**整體建議順序**：
催化劑農法 → 穩定高階裂痕刷圖 → 高譫妄速刷 → 使用額外資金進行腰帶製作
