# 深淵賺錢策略－高價值預兆

> 適用版本：POE2 0.5（實際機制與市場價格可能隨更新調整）  
> 策略定位：高投入、高操作要求，專門增加高價值深淵預兆的取得機會。

## 一、策略概要

這套玩法的核心不是進入無盡深淵或擊殺三名一般深淵頭目，而是：

1. 在地圖中生成更多深淵與深淵稀有怪物。
2. 透過輿圖天賦固定遭遇「阿姆那姆」勢力。
3. 尋找帶有阿姆那姆黑霧機制的稀有怪物。
4. 將怪物引出黑霧後擊殺，取得高價值深淵預兆的掉落機會。

主要目標包含：

- **光明之兆**
- **深淵回響之兆**
- **腐化之兆**
- **右旋死靈術之兆**
- 其他具有交易價值的深淵預兆

預兆價值會隨聯盟進度與市場供需變動，刷圖前應先查看即時行情，不建議在攻略中固定標示價格。

## 二、核心機制

### 1. 為什麼要選阿姆那姆勢力

高價值預兆主要與帶有阿姆那姆特殊黑霧機制的深淵稀有怪有關。因此，輿圖天賦應透過「力量平衡」固定遭遇阿姆那姆，避免將地圖事件分散到其他深淵勢力。

### 2. 黑霧內外會影響掉落結果

遇到會生成黑霧的阿姆那姆稀有怪時，不要直接在黑霧內擊殺。

玩家實測結果顯示：

- 在黑霧內擊殺，常見結果為低價值的「諸侯之兆」。
- 將怪物引出黑霧後擊殺，才會開啟光明之兆、深淵回響之兆等高價預兆的掉落結果。

這項互動已有多名玩家重複測試，但目前缺乏官方公開的完整掉落公式。因此較準確的說法是：

> 將阿姆那姆稀有怪引出黑霧後擊殺，是取得高價值深淵預兆的重要條件，但不代表每次都會掉落預兆，也不保證必定掉落光明之兆。

## 三、前置條件

| 項目 | 建議條件 |
|---|---|
| 地圖區域 | 優先選擇能同時受到多座先行者高塔影響的區域 |
| 地圖布局 | 開闊、好移動、方便拉怪離開黑霧 |
| 碑牌投入 | 高投入；先確認單張地圖實際受到的碑牌數量與詞綴 |
| 輿圖天賦 | 固定阿姆那姆勢力，並提高深淵怪物、坑洞與深淵物品收益 |
| 角色能力 | 足以穩定處理高效用稀有怪，並能控制輸出停止時機 |
| 技能需求 | 避免無法停止的持續傷害、超大範圍清怪或失控召喚物 |

## 四、輿圖天賦配置

### 核心必選

| 天賦 | 作用 |
|---|---|
| **力量平衡** | 選擇阿姆那姆，使地圖固定遭遇該深淵勢力 |
| **卑劣珍寶** | 增加 50% 找到深淵物品的機率，影響深淵之眼、預兆與族裔輔助 |
| **蔓延裂縫** | 增加 25% 深淵生成的怪物數量 |
| **邪穢影響** | 增加深淵怪物擁有深淵詞綴與巫妖詞綴的機率 |

### 增加怪物與坑洞

| 天賦 | 作用 |
|---|---|
| **來自地底** | 每個深淵固定增加 1 個坑洞 |
| **黑暗深淵** | 機率增加 2～4 個坑洞 |
| **坑洞之主** | 操縱坑洞分布，並透過關閉坑洞提高深淵怪物效用 |

其中「坑洞之主」會提高怪物效用，使怪物更耐打，但同時增加經驗與物品掉落數量。角色傷害或生存不足時，不宜為了理論收益強行堆高效用。

### 非本策略核心

以下天賦可以依剩餘點數選擇，但不是高價預兆流的首要來源：

- **慘白遺物**：偏向深淵保險箱收益。
- **腐敗枯骨**：偏向遠古褻瀆通貨。
- **根源祝福**：偏向水井之心珠寶。
- **接近地表、深淵之怒、無盡深淵機率**：主要強化無盡深淵或頭目內容，與本策略目標不同。

## 五、碑牌配置

### 詞綴優先順序

碑牌的目標是同時放大「深淵事件數量」與「稀有怪收益」。建議優先尋找：

1. 地圖內的深淵生成額外稀有怪物。
2. 地圖含有額外深淵。
3. 增加地圖內稀有怪物數量。
4. 增加怪物效用或其他能提高掉落收益的詞綴。
5. 增加怪物數量或物品稀有度的通用打寶詞綴。

### 建議搭配

原策略採用「2＋2」配置：

- 2 塊偏向一般打寶：稀有怪物數量、怪物數量、物品稀有度。
- 2 塊偏向深淵：額外深淵、深淵稀有怪物、深淵出現相關詞綴。

這種配置的目的，是避免所有碑牌都只堆額外深淵，導致地圖空間不足、事件重疊或部分深淵無法正常展開。「過多深淵會被吞掉」目前屬於玩家實戰觀察，並非官方公布的固定上限。

### 0.5 版本注意事項

0.5.0 已修正「每塊深淵碑牌錯誤地額外增加 1 個深淵」的問題。現在深淵碑牌的基礎功能是讓地圖能生成深淵；實際增加多少深淵，必須查看碑牌上的額外詞綴，不能直接用碑牌數量推算。

因此，配置碑牌時應逐張確認：

- 地圖實際受到幾塊碑牌影響。
- 每塊碑牌有哪些有效詞綴。
- 額外深淵是否來自明確詞綴，而不是碑牌基底。

## 六、單張地圖操作流程

1. 選擇受到多塊合適碑牌影響、布局開闊的地圖。
2. 確認地圖具有深淵，並檢查高風險詞綴是否超出角色承受能力。
3. 開啟深淵，正常清理裂縫與坑洞生成的怪物。
4. 遇到稀有怪時，查看怪物名稱或詞綴，辨識是否為阿姆那姆黑霧怪。
5. 發現黑霧後立刻降低輸出，避免怪物在霧內被瞬間擊殺。
6. 人物離開黑霧，並將圖騰、召喚物或持續傷害效果一併控制在霧外。
7. 將稀有怪引出黑霧；確認怪物與玩家都位於黑霧外後再擊殺。
8. 完成剩餘深淵，統計高價預兆、一般預兆與其他深淵收益。

## 七、拉怪操作重點

### 正確做法

- 看到黑霧後先停止爆發輸出。
- 移動到黑霧外，等待怪物追出來。
- 確認怪物模型已完全離開黑霧範圍。
- 在霧外集中火力擊殺。

### 常見失敗原因

- 範圍技能提前擊殺怪物。
- 中毒、點燃等持續傷害在拉怪途中將怪物殺死。
- 圖騰或召喚物留在黑霧內持續攻擊。
- 地圖過於狹窄，怪物無法順利離開黑霧。
- 怪物效用堆得太高，拉怪時被其他怪物包圍擊殺。

若流派無法控制召喚物或持續傷害，這套策略的實際收益可能明顯低於理論值。

## 八、收益判斷

### 主要收益

- 高價值深淵預兆。
- 其他一般深淵預兆。
- 深淵之眼、族裔輔助與褻瀆相關物品。
- 稀有怪物帶來的一般通貨與裝備收益。

### 成本

- 高詞綴碑牌。
- 建立多座高塔覆蓋區域的準備成本。
- 高難度換界石與刷圖消耗。
- 拉怪造成的額外時間成本。
- 操作失誤導致高價掉落池未被正確觸發的風險。

### 建議統計方式

至少以 20～50 張地圖為一組記錄：

| 統計項目 | 用途 |
|---|---|
| 地圖總數 | 建立基本樣本量 |
| 總投入 | 碑牌、換界石及其他消耗 |
| 每張深淵數量 | 確認配置是否真正生效 |
| 阿姆那姆黑霧稀有怪數量 | 評估核心事件出現率 |
| 成功拉出黑霧的擊殺數 | 排除操作失誤 |
| 各類預兆數量與售價 | 計算主要收益 |
| 其他可出售物品 | 計算副收益 |
| 每小時淨收益 | 比較其他賺錢策略 |

不要只用單張地圖或單次光明之兆掉落判斷策略是否獲利。

## 九、適合與不適合的玩家

### 適合

- 已完成主要輿圖天賦配置。
- 有足夠資金購買高品質碑牌。
- 角色能穩定處理高效用稀有怪。
- 技能可以隨時停止輸出並精確拉怪。
- 願意記錄長期樣本，而不是依賴單次掉落。

### 不適合

- 資金不足以承受數十張地圖的波動。
- 使用難以停止輸出的持續傷害或自動召喚流派。
- 角色容易在高密度深淵戰鬥中死亡。
- 只想快速清圖，不願為黑霧怪單獨操作。

## 十、結論

高價值預兆流的收益核心可以簡化為：

> 固定阿姆那姆勢力 → 增加深淵與稀有怪 → 找到黑霧稀有怪 → 引出黑霧後擊殺。

碑牌與輿圖天賦只能增加遇到目標怪物的機會；真正決定高價掉落池能否被觸發的關鍵，是辨識黑霧怪並在正確位置完成擊殺。這套玩法的收益上限高，但成本、地圖布局、角色流派與操作穩定度都會直接影響結果。
