# 如何查價－終局物品

> 版本基準：POE2 0.5 版。
>
> 內容來源：第一部影片 A06。本文只建立查價與決策原則，不記錄固定市場價格。

## 1. 為什麼要先查價

終局機制會產出門票、材料、預兆、傳奇物品與特殊任務道具。它們的價值會隨聯盟進程、版本改動、流派需求與市場供給變化，不應只依稀有度、名稱或影片錄製時的價格判斷。

優先查價的物品包括：

- 頭目門票、邀請與碎片。
- 預兆、液態情感、古老骨頭等機制材料。
- 裂痕胎贈、探險日誌與特殊強化道具。
- 限定傳奇、珠寶、魔偶與頭目產物。
- 詞綴數值、插槽或組合會影響價格的物品。

## 2. 基本查價流程

1. 確認物品的台服正式名稱與類型。
2. 使用遊戲內查價功能取得初步行情。
3. 檢查物品的詞綴數值、物品等級、品質、插槽與特殊狀態。
4. 排除明顯異常、長期未成交或用來誤導行情的掛價。
5. 比較相同條件的多筆結果，而非只看最低一筆。
6. 再決定出售、自用、推遲、重骰或投入加工。

## 3. 不同物品的判斷方式

| 物品類型 | 查價重點 | 常見錯誤 |
|---|---|---|
| 通貨與可堆疊材料 | 單價、堆疊量、批量交易價 | 只看單件最低價 |
| 頭目門票與邀請 | 門票成本、角色成功率、頭目掉落期望 | 忽略出售的機會成本 |
| 傳奇物品 | 關鍵詞綴、數值區間、腐化或特殊狀態 | 把同名物品視為同價 |
| 製作材料 | 當前流派與工藝需求 | 因外觀普通而低估 |
| 任務道具 | 是否為必要進度物品、能否交易 | 誤售或誤用任務物品 |
| 低成交量特殊物品 | 掛價時間、實際需求、相似成交範圍 | 把單一高掛價當成市價 |

## 4. 出售或自用

可用以下方式判斷：

> 預期產物價值 − 門票或材料出售價值 − 額外投入成本 − 失敗風險 − 交易時間

### 優先出售

- 尚未理解機制流程。
- 角色無法穩定完成內容。
- 尚未取得關鍵輿圖天賦。
- 不熟悉產物的價值差異。
- 資金不足以承擔數次低收益或失敗。

### 考慮自用

- 能穩定完成對應機制與頭目。
- 已配置關鍵機制天賦。
- 能辨識主要產物與高價詞綴。
- 有足夠資金承擔收益波動。

## 5. 查價注意事項

- 不沿用影片或舊文章中的固定價格。
- 不以單一掛價判斷真實成交價。
- 不忽略詞綴數值、剩餘使用次數或特殊狀態。
- 高價物品若成交量低，應拉長觀察時間或採較保守估值。
- 不確定是否為任務道具時，先保留並確認用途。
