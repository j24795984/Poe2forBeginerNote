# 影片整理－探險

> 內容狀態：與既有的「探險－基本說明」及「賺錢策略－探險」高度涵蓋。現階段仍依第一部影片完整保留，尚未進行逐段比較、校訂與整合。
>
> 來源範圍：F01～F05，約 10:36～13:24。

## 1. 基本流程

1. 在一般地圖中完成探險。
2. 取得探險日誌。
3. 將探險日誌放在角色背包。
4. 使用日誌揭露海洋與島嶼區域。
5. 前往大型探險、特殊洞穴與島嶼頭目。

普通探險主要提供日誌；大型探險則承接高階產物、永久獎勵與任務推進。

## 2. 「東遊記」支線

1. 在探險內容中取得「東遊記」。
2. 帶回第四章金司馬區廢墟。
3. 交給丹尼格處理。
4. 解鎖特殊傳奇物品製作相關內容。

此支線不屬於四名島嶼頭目的必要主線，應與主要任務分開理解。

## 3. 探險五名頭目

影片所稱「探險五王」，實際結構為：

- 四名島嶼頭目。
- 一名最終巔峰頭目。

四名島嶼頭目會提供首次永久獎勵，需要依不同日誌、區域階級與任務條件挑戰。擊敗奧爾羅斯後，可修復關鍵道具並前往最終區域。

任務用日誌與首次永久獎勵不建議跳過；擊敗頭目後，也應完成相應的 NPC 對話。

## 4. 「阿德爾的傳奇」

「阿德爾的傳奇」會強化下一次使用探險日誌所揭露的大型探險。

使用流程：

1. 將道具放在背包。
2. 右鍵啟用。
3. 使用下一本探險日誌揭露海域。
4. 道具觸發並消耗。

它是高成本、高風險的強化道具，不適合作為一般日誌的固定消耗品。角色與知識尚未成熟時，可先查價並考慮出售。

## 5. 推薦刷法

> 分類標註：本節對應 F05。為保留影片脈絡而完整寫入本檔；網站正式發布時，應歸入「賺錢策略－探險」，不與基本說明重複刊載。

1. 進入大型探險後，先查看完整地圖。
2. 確認角色無法處理的遺物詞綴。
3. 找出高符文插槽遺物、力量符文與大型符文怪物。
4. 規劃炸藥順序，讓重要遺物盡量在路線前段生效。
5. 再利用剩餘炸藥連接其他特殊遺物與獎勵。
6. 不要為普通箱子犧牲整體路線。

不熟悉遺物、符文或大型探險時，可先出售日誌，避免承擔錯誤路線與失敗成本。
