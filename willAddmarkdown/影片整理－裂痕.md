# 影片整理－裂痕

> 內容狀態：尚未建立完整裂痕專題文件。本文先完整保留第一部影片的任務、天賦與創生之樹內容，後續再深入查證與擴充。
>
> 來源範圍：D01、D02、D03，約 06:24～09:05。

## 1. 一般裂痕

1. 在地圖中開啟不穩定裂痕。
2. 擊殺裂痕怪物，延長裂痕持續時間。
3. 持續推進並擊殺足夠的怪物。
4. 裂痕穩定後，處理更強的敵人。
5. 完成後取得裂痕斷片、胎贈或其他機制產物。

## 2. 裂痕據點與任務

1. 前往「看守者的修道院」與周邊裂痕區域。
2. 完成據點周圍的指定地圖。
3. 取得裂痕輿圖天賦點並推進任務。
4. 收集裂痕斷片與相關產物。
5. 取得裂痕石後，依任務指示揭露後續區域。

## 3. 裂痕石與巢穴

- 裂痕石需要放在角色背包中，輿圖才會顯示相關可揭露區域。
- 使用裂痕石推進裂痕據點或巢穴內容。
- 在裂痕巢穴中協助並保護艾里絲完成摧毀核心的程序。
- 完成相關頭目後，返回據點與 NPC 對話。

### 容易卡住的位置

- 裂痕石沒有放在角色背包。
- 尚未完成據點周圍的指定地圖。
- 防守過程中艾里絲死亡，導致巢穴未完成。
- 擊敗頭目後沒有完成 NPC 對話。
- 任務道具與一般裂痕產物混放或誤用。

## 4. 創生之樹

創生之樹是處理裂痕胎贈與相關產物的重要系統。不同胎贈可能對應不同獎勵與後續用途，投入前應確認：

- 胎贈的類型與階級。
- 可取得或轉換的物品範圍。
- 是否值得繼續培育、開啟或出售。
- 該物品是否為任務所需。

不同胎贈不應視為同等價值；高階胎贈與特殊產物應先查價。

## 5. 天賦配置方向

初期可優先考慮：

- 增加不穩定裂痕出現機率。
- 增加裂痕怪物群或稀有怪物。
- 強化裂痕巢穴的波次與獎勵。
- 改善胎贈的掉落與階級。

頭目與高階內容尚未解鎖前，先配置一般裂痕與巢穴相關節點；完成巔峰內容後，再處理高階專精節點。
