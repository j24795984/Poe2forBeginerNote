# 影片整理－祭祀

> 內容狀態：與既有的「祭祀－基本說明」及「賺錢策略－祭祀」高度涵蓋。現階段仍依第一部影片完整保留，尚未進行逐段比較、校訂與整合。
>
> 來源範圍：B01、B02，約 01:56～05:11。

## 1. 任務起點

1. 前往輿圖西側的祭祀據點「凱爾塔斯」。
2. 完成據點周圍帶有祭祀內容的地圖。
3. 與相關 NPC 對話，推進祭祀任務。
4. 取得初期祭祀輿圖天賦點。

## 2. 一般祭祀

1. 清除祭祀法陣內的怪物。
2. 啟動祭祀神壇。
3. 擊殺被神壇復活的怪物。
4. 取得貢禮並查看恩惠之物。
5. 依價值與貢禮數量選擇兌換、推遲或重骰。

未使用的貢禮可以獻祭，用來累積「覲見國王」相關進度。當恩惠清單中沒有值得兌換或推遲的物品時，不要讓剩餘貢禮直接浪費。

## 3. 後續頭目與任務

1. 累積並使用「覲見國王」。
2. 前往無量困境，挑戰迷霧之王。
3. 擊敗迷霧之王後取得「國王首級」。
4. 將國王首級用於後續「無名之儀」任務。
5. 依任務要求連續完成多張祭祀地圖。

「國王首級」屬於後續流程的關鍵道具，不應未確認用途便視為一般收益物品處理。

## 4. 容易卡住的位置

- 尚未完成凱爾塔斯周圍的地圖。
- 完成地圖後沒有與 NPC 對話。
- 不知道剩餘貢禮可以轉換為覲見國王進度。
- 將國王首級誤認為一般可出售產物。
- 不清楚無名之儀需要連續完成多張地圖。

## 5. 天賦配置方向

初期先完成凱爾塔斯周邊內容並取得祭祀天賦點，再依需求考慮：

- 增加貢禮。
- 降低推遲成本。
- 增加恩惠或重骰機會。
- 加速覲見國王進度。

角色尚未成熟時，不宜過早配置會大幅提高怪物強度的節點。完成高階任務或頭目後，再處理無名之儀與高階祭祀相關天賦。
