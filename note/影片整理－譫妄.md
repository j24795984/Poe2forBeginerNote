# 影片整理－譫妄

> 內容狀態：尚未建立譫妄專題文件。本文先完整保留第一部影片的基本流程與天賦方向，後續再補充與查證專題內容。
>
> 來源範圍：C01、C02，約 05:11～06:24。

## 1. 任務據點

1. 尋找譫妄據點「凋萎敗柳」。
2. 完成據點周圍帶有譫妄內容的地圖。
3. 與相關 NPC 對話並推進任務。
4. 取得初期譫妄輿圖天賦點。

## 2. 地圖機制

1. 進入地圖並觸發譫妄迷霧。
2. 跟著迷霧方向向前推進。
3. 在迷霧中擊殺怪物，累積獎勵。
4. 依角色能力決定推進距離與譫妄程度。
5. 在迷霧結束前取得已累積的獎勵。

距離起點越遠，怪物強度與譫妄程度通常越高。離開迷霧範圍或推進速度不足，機制可能開始結束。

## 3. 後續內容

- 累積液態情感、幻像斷片及其他譫妄產物。
- 推進宏偉之鏡或相關特殊內容。
- 進入幻像異界，處理高階譫妄與頭目流程。

上述內容在影片中以概覽為主，尚未形成完整的門票、波次、頭目與收益攻略。

## 4. 天賦配置方向

取得凋萎敗柳周邊的初期天賦點後，可依角色能力選擇：

- 延緩迷霧消散。
- 增加鏡面或碎片相關收益。
- 增加液態情感。
- 強化幻像異界內容。

清圖能力不足時，先選擇能提高完成穩定性的節點，不必強求最高譫妄程度。

## 5. 注意事項

- 角色需要足夠的移動、清怪與生存能力。
- 清圖速度不足時，不適合強求最高譫妄程度。
- 頭目、特殊鏡面與碎片屬於後續進階內容。
- 影片只提供基本導航，建立正式專題前仍需補查完整流程與台服用語。
