# 賺錢策略－終局機制總覽

> 版本基準：POE2 0.5 版。
>
> 內容來源：第一部影片 G02，並收錄 F05 的探險農法摘要。本文只比較各機制的收益方向，不取代個別機制的深入策略文件。

## 1. 機制收益比較

| 機制 | 主要收益方向 | 入門處理方式 |
|---|---|---|
| 祭祀 | 預兆、傳奇物品、特殊祭祀恩惠 | 逐件查價；高價恩惠優先兌換或推遲 |
| 譫妄 | 液態情感、幻像斷片、譫妄特殊產物 | 清圖能力不足時先出售材料，不強求高譫妄程度 |
| 裂痕 | 裂痕石、胎贈、創生之樹產物 | 胎贈與特殊產物先確認用途和價格 |
| 深淵 | 古老骨頭、深淵之眼、褻瀆材料、頭目產物 | 高價骨頭先查價；不熟悉褻瀆時優先出售 |
| 探險 | 探險日誌、遺物、符文、維里西姆、頭目道具 | 不熟悉大型探險時先出售日誌 |

## 2. 共通投入原則

- 不熟悉機制時，優先出售可交易門票與材料。
- 已完成任務與天賦配置後，再評估自行使用。
- 高成本門票與強化道具，需要計入失敗風險。
- 特殊產物應逐件查價，不沿用影片中的固定價格。
- 角色無法穩定完成時，不因理論收益高就直接投入。

投入前可用下式估算：

> 預期產物價值 − 門票或材料出售價值 − 額外投入成本 − 失敗風險 − 交易時間

## 3. 探險農法摘要

> 內容狀態：本節來自 F05，與既有「賺錢策略－探險」高度涵蓋。先保留影片版摘要，尚未進行逐段比較與整合。

進入大型探險後：

1. 先觀察整張地圖，不要立即放置炸藥。
2. 排除角色無法處理的遺物詞綴。
3. 優先高符文插槽遺物、力量符文與大型符文怪物。
4. 將高價遺物盡量放在爆破路線前段。
5. 不要為一般箱子犧牲整體路線。
6. 不熟悉大型探險時，可先出售日誌。

待比較文件：[賺錢策略－探險](./賺錢策略-探險.md)

## 4. 成長順序

1. 完成機制據點與基礎任務。
2. 取得初期機制輿圖天賦點。
3. 先出售不熟悉的門票與材料，累積資金。
4. 熟悉產物價值與失敗條件。
5. 完成關鍵天賦配置後，開始自行投入。
6. 角色與資金成熟後，再採用高成本強化與頭目策略。
