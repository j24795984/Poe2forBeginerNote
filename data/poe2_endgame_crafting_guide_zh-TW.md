# POE2 後期與畢業裝製作流程

> 適用範圍：聯盟角色  
> 核心原則：**最難重現的詞先做、最怕失去的詞先破裂、完成其中一側後只操作另一側。**

---

## 一、核心觀念：先做最難取得的詞，再嘗試破裂

後期與畢業裝常見的製作思路是：

```text
先取得整件裝備中最難重現的核心詞綴
→ 將裝備補到可使用破裂石的條件
→ 使用破裂石嘗試鎖定核心詞綴
→ 成功後圍繞破裂詞綴重製其餘詞綴
```

破裂石的用途不是直接完成畢業裝，而是：

> 將一個極難重現的製作步驟，轉變成永久完成的基礎。

但不是每件後期裝備都必須先破裂。

```text
目標裝備是否有一條非常難取得、失去後很難重做的詞綴？
├─ 有：優先考慮先取得該詞，再嘗試破裂
└─ 沒有：可直接使用精髓、預兆、混沌石與崇高石製作
```

---

## 二、什麼是「最難取得的詞」

最難取得的詞不一定只是數值最高，而是通常具備以下一項或多項特徵：

- 詞綴權重極低。
- 只能在高物品等級基底上出現。
- 只有特定武器、護甲、珠寶或特殊基底能出現。
- 無法透過精髓、Alloy 或其他方式穩定保證。
- 屬於聯盟、褻瀆或特殊機制詞綴。
- 與其他必要詞綴競爭相同的前綴或後綴位置。
- 一旦被移除，就很難重新取得。
- 詞綴本身決定流派是否成立，而不只是提高少量傷害。

常見例子：

- 高階技能等級。
- 頂階物理傷害或元素傷害詞。
- 稀有投射物、連鎖或額外技能效果。
- 頂階局部防禦詞。
- 權杖、法杖上的流派核心技能詞。
- 特定聯盟或褻瀆詞綴。

### 是否值得破裂的判斷

製作前先回答：

1. 這條詞是否無法穩定保證取得？
2. 失去後是否需要投入大量資源重新製作？
3. 這條詞是否會直接決定整件裝備的價值？
4. 成功破裂後，是否能顯著降低後續製作成本？
5. 基底價值是否足以承擔破裂石成本？

若多數答案為「是」，便適合考慮破裂。

---

# 三、破裂製作的完整準備流程

## 步驟 1：先定義最終詞綴

製作前先把目標拆成前綴與後綴。

```text
前綴 1：核心詞 A
前綴 2：核心詞 B
前綴 3：次要詞 C

後綴 1：核心詞 D
後綴 2：實用詞 E
後綴 3：實用詞 F
```

例如物理武器：

```text
前綴
1. 增加物理傷害
2. 附加物理傷害
3. 技能等級或混合物理詞

後綴
1. 攻擊速度
2. 暴擊率
3. 暴擊加成或其他輸出詞
```

接著確認：

- 哪一條最難自然骰出？
- 哪一條無法透過精髓保證？
- 哪一條失去後，整件裝備就不值得繼續？
- 哪一條值得承擔破裂石成本？

這一條就是主要破裂目標。

---

## 步驟 2：選擇正確基底與物品等級

取得核心詞前，先確認：

- 基底固有能力是否正確。
- 武器攻擊速度、暴擊率或防具基礎值是否適合。
- 物品等級是否能出現全部目標詞綴。
- 是否需要特定聯盟、褻瀆或 Runic 類型。
- 基底本身是否值得投入高價材料。
- 成品是否具有自用或市場價值。

常見錯誤：

- 在錯誤基底上做出昂貴詞綴。
- 基底物品等級不足。
- 基底雖能出現核心詞，卻無法出現其他目標詞。
- 武器基礎攻速或暴擊率不適合流派。
- 防具基礎防禦值過低。

---

## 步驟 3：取得核心詞綴

### 方法 A：直接購買核心詞基底

通常是最務實的方法。

搜尋條件應包含：

```text
正確基底
＋
正確物品等級
＋
目標高階詞綴
＋
其他詞綴越少越好
```

適合情況：

- 核心詞權重極低。
- 市場上已有可用基底。
- 自行製作的平均成本高於購買成本。
- 希望直接進入破裂階段。

### 方法 B：自行骰出核心詞

適合情況：

- 基底便宜且供應充足。
- 目標詞能在魔法裝階段出現。
- 高階或完美蛻變石成本可接受。
- 市場上沒有適合基底。

流程：

```text
白色基底
→ 高階或完美蛻變石
→ 未出現核心詞則更換基底或重來
→ 出現核心詞後視情況使用增幅石
→ 使用富豪石升為稀有裝
```

注意：

- 高階與完美貨幣只會提高新增詞綴的最低等級。
- 不代表一定取得 T1。
- 不代表一定取得指定詞綴。

### 方法 C：精髓、Alloy 或特殊機制

適合：

- 目標詞可由指定材料保證。
- 詞綴本身具有流派核心功能。
- 自然取得成本高於保證製作成本。

但通常：

> 可以穩定保證取得的詞，不一定是最值得破裂的詞。

真正值得破裂的通常是：

- 沒有保證方式的自然高階詞。
- 特殊詞綴。
- 極低權重詞綴。
- 重新取得成本極高的詞綴。

---

## 步驟 4：補足破裂條件

破裂石需要作用於：

```text
稀有物品
＋
至少四條詞綴
```

如果目前只有核心詞和少量其他詞，需要先補到至少四條。

```text
核心詞
＋
普通詞 A
＋
普通詞 B
＋
普通詞 C
＝四條詞綴
```

### 重要原則

在符合最低四條詞綴的前提下，不要無意義地補滿六條。

若所有詞綴皆可能成為破裂目標：

| 可被破裂的詞綴數 | 破裂到指定一條的基礎機率 |
|---:|---:|
| 4 | 25% |
| 5 | 20% |
| 6 | 約 16.7% |

因此，通常以四條詞綴嘗試破裂最合理。

---

## 步驟 5：降低破裂失敗損失

理想的破裂基底不是：

```text
目標詞：極高價值
其他三條：完全無效
```

而是：

```text
目標詞：畢業級
其他詞 A：具有市場價值
其他詞 B：可用於另一種製作
其他詞 C：至少不是完全無效
```

這樣即使沒有破裂到主要目標，也可能：

- 轉為其他流派的製作基底。
- 出售回收部分成本。
- 改成後期過渡裝。
- 轉換製作方向。

---

# 四、破裂結果處理

## 結果 A：成功破裂核心詞

```text
成功破裂核心詞
→ 正式進入後續製作
```

## 結果 B：破裂到另一條有價值詞綴

```text
偏離原本計畫
→ 重新評估製作方向
→ 改做其他裝備或出售
```

## 結果 C：破裂到無效詞綴

```text
通常停止投入
→ 出售、過渡使用或放棄
```

原因：

- 破裂詞綴無法移除或改變。
- 無效詞綴會永久占用一個前綴或後綴位置。
- 繼續投入高價材料通常不符合成本效益。

---

# 五、成功破裂後的後期裝製作流程

後期裝目標通常是：

```text
1 條破裂核心詞
＋
2 至 3 條主要有效詞
＋
1 至 2 條實用詞
```

約有四至五條有效詞綴，通常已足以穩定刷 T16。

## 步驟 1：確認破裂詞的位置

先確認破裂詞屬於前綴或後綴。

例如：

```text
[破裂] +技能等級：前綴
```

剩餘位置：

```text
前綴空間：2
後綴空間：3
```

接下來要判斷：

- 第二重要詞位於前綴還是後綴？
- 精髓或 Alloy 保證詞會占哪一側？
- 哪一側比較難完成？
- 應先完成前綴還是後綴？

## 步驟 2：建立第二核心詞

第二核心詞常見來源：

- 完美精髓。
- Alloy。
- 褻瀆。
- 混沌石替換。
- 高階或完美崇高石。
- 定向增加前綴或後綴的預兆。

典型結構：

```text
[破裂] 最難自然詞
＋
完美精髓或 Alloy 保證的第二核心詞
```

## 步驟 3：完成較難的一側

例如前綴已完成：

```text
前綴
[破裂] 技能等級
高法術傷害
高附加傷害

後綴
普通詞
垃圾詞
空
```

後續原則：

```text
不再使用可能破壞前綴的操作
→ 只針對後綴進行移除、替換與新增
```

反之，若後綴已完成，便只處理前綴。

## 步驟 4：使用預兆控制移除側別

為避免破壞已完成的一側，可以搭配控制前綴或後綴移除的預兆。

例如前綴已完成，需要處理後綴：

```text
啟用只移除後綴的預兆
→ 使用完美精髓
→ 從後綴中移除一條
→ 加入精髓保證詞
→ 保留已完成前綴
```

## 步驟 5：定向補空詞

崇高石會新增一條隨機詞綴。

高階與完美版本能限制新增詞綴的最低等級，但不保證指定詞。

若前綴與後綴都有空位，應先考慮：

- 定向新增前綴。
- 定向新增後綴。
- 使用對應預兆。
- 珠寶使用 Catalyst Quality 提高特定類型詞綴機率。

## 步驟 6：後期裝停手點

合理停手標準：

```text
破裂核心詞：1
主要有效詞：3
次要有效詞：1
無效或普通詞：最多 1
```

後期裝的主要目的：

- 穩定刷 T16。
- 補足整體抗性與防禦。
- 達成流派關鍵門檻。
- 將資源平均投入全身。

# 六、畢業裝完整製作流程

畢業裝通常追求：

- 正確最高階基底。
- 正確物品等級。
- 五至六條高階有效詞綴。
- 核心詞綴已破裂或受到可靠保護。
- 詞綴數值接近最大值。
- 品質、插槽與符文完整。
- 完成聖化或腐化等最終加工。

## 階段 1：取得並破裂最難詞

```text
正確頂級基底
→ 取得最難核心詞
→ 補足至少四條詞綴
→ 使用破裂石
→ 未破裂到目標則停止、出售或重做
→ 破裂到目標才進入下一階段
```

不要因已投入大量成本，就在錯誤破裂結果上繼續投入。

## 階段 2：建立第二核心詞

```text
破裂核心詞
＋
精髓、Alloy、褻瀆或其他保證詞
```

規劃時先列出：

```text
破裂詞：最難自然取得的詞
保證詞：第二重要且可定向取得的詞
特殊詞：聯盟、褻瀆或機制詞
隨機詞：剩餘可接受詞
```

## 階段 3：完成較難的一側

若前綴較難完成，就先完成前綴；一旦完成，後續只處理後綴。反之亦然。

## 階段 4：處理第三至第五條詞

常見循環：

```text
定向移除錯誤詞
→ 定向增加需要的一側
→ 檢查新增詞綴與階級
→ 達標則保留
→ 未達標則評估是否繼續
```

混沌石適合：

- 裝備只有一條明顯錯誤詞。
- 其他核心詞已被破裂保護。
- 可透過預兆限制移除前綴或後綴。
- 失敗後仍有恢復路線。

不適合：

- 已有五條高價詞綴。
- 只有最後一條不完美。
- 移除任何一條都可能使裝備大幅貶值。

## 階段 5：最後一條詞的風險評估

需要比較：

```text
目前裝備價值
vs.
最後一條詞的平均製作成本
vs.
失敗後的損失
vs.
實際角色提升幅度
```

值得繼續的情況：

- 最後一詞會改變技能機制。
- 可達成關鍵攻擊速度或施法速度門檻。
- 可補足暴擊、命中或抗性必要門檻。
- 明確追求極致展示或最高傷害。
- 預算允許多次重做。

應停止的情況：

- 只提升少量傷害。
- 失敗可能破壞高價五詞成品。
- 製作成本遠高於實際提升。
- 可透過其他部位更便宜地補足需求。

# 七、數值調整與最終加工

## 1. 神聖石

適合使用時機：

- 詞綴種類已正確。
- 詞綴階級已正確。
- 裝備已接近完成。
- 只剩數值區間需要改善。
- 數值差距確實會影響傷害或防禦。

## 2. 聖化

```text
完成主要詞綴
→ 完成數值調整
→ 確認不需再進行高風險修改
→ 進行聖化
```

## 3. 品質、插槽與符文

處理前先確認：

```text
後續操作是否可能使目前加工失效？
├─ 會：延後處理
└─ 不會：可先完成
```

## 4. 腐化

腐化通常為最後一步：

```text
完成詞綴
→ 完成數值
→ 完成品質
→ 完成插槽
→ 完成符文
→ 確認不再需要普通修改
→ 最後腐化
```

可能風險：

- 裝備被改壞。
- 插槽或詞綴發生變化。
- 裝備無法再正常修改。
- 沒有獲得有效提升。

# 八、後期裝與畢業裝差異

| 項目 | 後期裝 | 畢業裝 |
|---|---|---|
| 主要目的 | 穩定刷 T16 | 追求極致性能 |
| 是否一定破裂 | 不一定 | 常見，但仍視詞綴而定 |
| 有效詞綴數 | 約 4～5 條 | 約 5～6 條 |
| 詞綴階級 | 中高階即可 | 高階或頂階 |
| 可接受無效詞 | 最多約 1 條 | 通常不接受 |
| 主要方式 | 精髓、預兆、崇高、符文 | 破裂、分側製作、完美貨幣、定向預兆 |
| 資源管理 | 嚴格控制成本 | 接受多次重做 |
| 停手依據 | 已可穩定推進內容 | 邊際提升不值得風險 |

# 九、後期裝通用流程

```text
1. 決定至少四條必要詞綴
2. 購買或取得正確高物品等級基底
3. 判斷是否存在值得破裂的極難詞
4. 沒有極難詞：直接使用精髓或高階貨幣製作
5. 有極難詞：先取得核心詞並嘗試破裂
6. 成功後建立第二核心詞
7. 先完成較難的前綴或後綴
8. 使用預兆保護已完成的一側
9. 補到四至五條有效詞
10. 達到 T16 需求後停手
```

# 十、畢業裝通用流程

```text
1. 列出完整六詞目標與替代詞
2. 確認基底、物品等級與詞綴池
3. 取得最難自然詞
4. 將裝備整理成適合破裂的最低詞數
5. 使用破裂石
6. 只有破裂到主要目標才繼續
7. 使用精髓、Alloy 或褻瀆建立第二核心詞
8. 先完成較難的前綴或後綴
9. 使用預兆保護已完成的一側
10. 定向處理另一側
11. 使用高階或完美崇高石補詞
12. 使用神聖石調整數值
13. 完成品質、插槽、符文與聖化
14. 最後才考慮腐化
```

# 十二、核心結論

> **最難重現的詞先做。**  
> **最怕失去的詞先破裂。**  
> **完成其中一側後，只操作另一側。**

後期裝的重點是以合理成本完成四至五條有效詞，穩定刷 T16。

畢業裝則是在成功破裂核心詞之後，透過精髓、Alloy、預兆、高階貨幣與分側製作，逐步完成五至六條高階有效詞綴，最後才進行神聖、聖化、符文與腐化等加工。
